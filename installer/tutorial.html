Protetor de ecra vs. Live Wallpaper — qual e a diferenca?

Sao duas formas diferentes de mostrar o Johnny Castaway. Podes usar uma, outra, ou as duas ao mesmo tempo (nao entram em conflito).

Protetor de ecra

So aparece quando o computador fica inativo (sem mexer no rato/teclado) durante o tempo que definires em Definicoes do Windows. Cobre o ecra inteiro. Assim que mexes no rato ou premes uma tecla, desaparece e volta ao ambiente de trabalho normal. Instalado diretamente por este instalador.

Live Wallpaper

Fica sempre visivel, por baixo dos icones do ambiente de trabalho, como se fosse o proprio fundo de ecra — mesmo enquanto estas a trabalhar, com janelas abertas por cima. Nao desaparece quando mexes no rato. Precisa do Wallpaper Engine (Steam, gratuito) — ver secao dedicada mais abaixo.

Como instalar

Ao correr o instalador, chegas a uma pagina onde escolhes o que instalar:

  • Motor Johnny Castaway — obrigatorio, e o programa em si.
  • Protetor de ecra do Windows — regista-o em Definicoes > Personalizacao > Ecra de bloqueio > Protetor de ecra, para que apareca na lista.
  • Obter ficheiros do jogo original — pede a imagem da disquete original (ver secao seguinte).

Para live wallpaper, nao ha nada para marcar aqui — segue a secao "Live Wallpaper com o Wallpaper Engine" mais abaixo depois de instalares.

Como configurar

Ha um dialogo grafico com todas as opcoes. Para o abrir:

  • No Menu Iniciar: Johnny Castaway Reborn > Configurar
  • Ou em Definicoes > Personalizacao > Protetor de ecra > escolhe "Johnny Castaway Reborn" > botao "Definicoes..."

O dialogo tem um seletor de idioma no topo (Portugues/English/Espanol) que traduz tudo instantaneamente. Os campos disponiveis:

CampoO que faz
Dia da historia1 a 11 — fixa a historia num dia especifico da narrativa
VelocidadePercentagem da velocidade normal (100=normal, 200=dobro)
Feriado0=automatico (deteta pela data), 1=Halloween, 2=St Patrick, 3=Natal, 4=Ano Novo
Noite0=automatico (deteta pela hora), 1=forcar noite, 2=forcar dia
Escala0=automatico, -1=preencher o ecra (distorce), -2=ajustar mantendo proporcao, 1-N=fator fixo

Depois de escolher, carrega em OK — fica guardado automaticamente e aplica-se da proxima vez que o protetor de ecra ou o live wallpaper (via Wallpaper Engine) corram.

Screensaver vs. Live Wallpaper — what's the difference?

These are two different ways to show Johnny Castaway. You can use one, the other, or both at the same time (they don't conflict).

Screensaver

Only appears when the computer is idle (no mouse/keyboard activity) for the time you set in Windows Settings. Covers the whole screen. As soon as you move the mouse or press a key, it disappears and you're back to the normal desktop. Installed directly by this installer.

Live Wallpaper

Stays always visible, behind the desktop icons, as if it were the desktop background itself — even while you're working, with windows open on top of it. It does not disappear when you move the mouse. Requires Wallpaper Engine (Steam) — see the dedicated section below.

How to install

When running the installer, you'll reach a page where you choose what to install:

  • Johnny Castaway engine — required, this is the program itself.
  • Windows screensaver — registers it in Settings > Personalization > Lock screen > Screen saver, so it shows up in the list.
  • Get the original game files — asks for the original floppy disk image (see next section).

For live wallpaper, there's nothing to check here — follow the "Live Wallpaper with Wallpaper Engine" section below after installing.

How to configure

There's a graphical dialog with all the options. To open it:

  • From the Start Menu: Johnny Castaway Reborn > Configurar
  • Or via Settings > Personalization > Screen saver > choose "Johnny Castaway Reborn" > "Settings..." button

The dialog has a language selector at the top (Portugues/English/Espanol) that translates everything instantly. Available fields:

FieldWhat it does
Story day1 to 11 — pins the story to a specific day in the narrative
SpeedPercent of normal speed (100=normal, 200=double)
Holiday0=auto (detects from date), 1=Halloween, 2=St Patrick, 3=Christmas, 4=New Year
Night0=auto (detects from time), 1=force night, 2=force day
Scale0=auto, -1=fill screen (distorts), -2=fit keeping aspect ratio, 1-N=fixed factor
MonitorWhich screen it appears on, when you have more than one (see the list shown in the dialog itself)
Mode0=single monitor, 1=clone (same on all), 2=extend (stretched across all)
Audio deviceWhich output it plays through, when you have more than one
CRT filterScanline effect, for a more retro look
Skip introGoes straight to the story, without showing the opening screen

Once you're done, click OK — it's saved automatically and applies next time the screensaver or the live wallpaper (via Wallpaper Engine) run.

How to get the original game files

RESOURCE.MAP and RESOURCE.001 are the property of Sierra/Dynamix and are not included. Known source for the original floppy disk image:

archive.org/details/000580-ScreenAnticsJohnnyCastaway

From the Start Menu, choose "Obter ficheiros do jogo original" and follow the steps:

  1. Download the original floppy disk image from the link above
  2. Paste the file path when asked — accepts .7z, .img, or an already-extracted folder
  3. The program extracts and decompresses everything automatically
  4. At the end, it also asks if you want the original sounds (downloaded from the JCOS project)
If this link stops working in the future, search for "Johnny Castaway 1992 floppy disk image" on the Internet Archive (archive.org) itself, or other abandonware/software preservation archives — the file is the original floppy disk image for "Screen Antics: Johnny Castaway".

Live Wallpaper with Wallpaper Engine (full tutorial)

Wallpaper Engine (Steam, cheap and frequently on sale/free with promos) is the recommended way to have Johnny Castaway as an animated background. It integrates directly with Windows' wallpaper system through an officially supported mechanism, instead of relying on undocumented tricks that can break with any Windows update.

Step 1 — Find jc_reborn.exe

Usually at C:\Program Files\Johnny Castaway Reborn\jc_reborn.exe.

Quick tip: from the Start Menu, right-click "Johnny Castaway" > More > Open file location — this opens Explorer right in that folder.

Step 2 — Open Wallpaper Engine

Via the system tray icon (next to the clock), or via your Steam Library > Wallpaper Engine > Play.

Step 3 — Create an "Application" wallpaper

In the Editor tab (top of the Wallpaper Engine window), click Create, then choose Application from the list of wallpaper types.

Step 4 — Point it at the executable

A field will appear to pick the executable file. Browse to the jc_reborn.exe from Step 1 and select it.

Step 5 — Command line arguments

There's a text field labeled "Command line arguments". Type exactly:

window nointro

  • window is essential — without it, the program tries to open fullscreen and Wallpaper Engine can't embed the window correctly.
  • nointro is optional, but avoids seeing the intro screen every time Wallpaper Engine restarts the wallpaper.

You can combine other options too, e.g. window nointro crt (CRT filter) or window nointro day=5 (pins story day 5) — see the command-line options table below.

Step 6 — Apply the wallpaper

The created wallpaper appears in your Wallpaper Engine library ("My Wallpapers" tab). Right-click it and choose Apply to Monitor, or double-click to apply to your main monitor.

If you have multiple monitors (including a portrait/vertical one), you can apply Johnny Castaway to just one and keep a different wallpaper on the rest — right-click > "Apply to Monitor 1/2/3".

Troubleshooting

Black screen or nothing happens:

  • Make sure RESOURCE.MAP and RESOURCE.001 are in the SAME folder as jc_reborn.exe — Wallpaper Engine runs the program from that folder.
  • Make sure you typed window in the arguments.

The wallpaper looks stretched or cropped: add scale=fit to the arguments (window nointro scale=fit) to fit while keeping the aspect ratio.

Want to change settings (day, speed, etc.) after applying: use the "Configurar" shortcut in the Start Menu (opens the graphical dialog) — it applies next time Wallpaper Engine reloads the wallpaper. Or edit the arguments directly in Wallpaper Engine itself.

Command-line options

OptionWhat it does
jc_reborn.exeFullscreen, full story
windowRuns windowed instead of fullscreen (always use with Wallpaper Engine)
monitorsLists detected monitors
audiodevicesLists audio devices
/cOpens the configuration dialog
speed=NSpeed percentage
day=1..11Pins the story day
scale=fit / fillScale mode (see dialog)
crtEnables the CRT filter
nointroSkips the intro screen
helpLists all available options
